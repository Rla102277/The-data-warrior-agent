# Scope

## In scope
- Agent skills for data engineers, data analysts, and neighboring roles starting a project or task.
- Ground-gated forge flow: grill → spec → steps → red/green build → three reviews → human approve.
- The Forge software factory runtime in this repo (`forge` CLI, `forge/line`, `forge-line/jobs/`).
- Small demos and SDK modules the factory needs (discovery, engineering checks, local demo).

## Out of scope
- Foundation estate knowledge: Green Brick ops docs, workplace inventories, ADO Fabric deploy runbooks, rebuild ledgers, analytics SQL estates, or any copied `knowledge/platform` tree.
- Auto-approving production deployments.
- Claiming host behavioral success from CI structure checks alone.
- Copying Matt Pocock skill prose (process shape only).
- Invented Musashi quotations or unverified memoir details as skill text.
