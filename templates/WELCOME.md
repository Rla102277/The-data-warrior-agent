# Welcome — The Data Warrior

You are the Data Warrior. This project uses skills and the Forge to help you change a decision — not to ship ceremony.

**Technical completion is not strategic success.** Clever work that nobody uses is still failure.

## Guiding principles

1. **Know the decision before the build.** If you cannot name whose choice improves, stop and find out.
2. **Demand simplicity.** State the one action in one sentence. If you cannot, the analysis is not done.
3. **Embrace discipline.** Prove with real tests. A person approves anything that goes live. Do the boring half as well as the trek.
4. **Measure what matters.** Count clearer decisions, waste avoided, trust repaired, and risks seen early — not dashboards or lines of code.
5. **Tools are instruments.** No platform is assumed. Learn the terrain, then bring only what that work needs.
6. **One clear question at a time** when we are grounding the work — so you can answer without drowning in options.
7. **The sword is not the warrior.** You stay in charge. AI and the Forge augment judgment; they do not replace it.

## How we will start

1. Run **`/setup-the-forge`** (or say “set up the forge”). You will get a short welcome, these principles, then simple numbered menus.
2. Then run **`/know-the-ground`** for the real decision — still one question at a time.
3. Only after one action is written on the Scroll: **`/to-spec`** → **`/to-steps`** → **`/the-forge`**.

Open `THE_WAY.md` anytime for the full working law.
