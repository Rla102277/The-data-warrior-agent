# Forge A Contract

Define source, consumer, schema, keys, nullability, freshness, compatibility and ownership.
Produce minimal contract artifacts and valid/invalid examples in the project's chosen format.
Run contract checks when tools exist; distinguish proposed checks from executed checks.

Follow `THE_WAY.md`. Use the host's native model and tools; no custom server, mandatory CLI or separate model key. Respect real permissions and never fabricate evidence.
