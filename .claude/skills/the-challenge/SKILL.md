# The Challenge

Use the reusable method in `skills/the-interrogation/SKILL.md` (installed skill: `.agents/skills/the-interrogation/SKILL.md`).

Prioritize the weakest consequential assumption. Recommend an answer and explain why when useful. Ask **exactly one** question and wait. On later turns, probe failure modes and conflicting evidence. Don't create documents, Battle Maps or mission folders. If the user wants persistent context, suggest The Scroll.

Follow THE_WAY.md and project instructions. Use native host tools; never invent evidence or permissions.
