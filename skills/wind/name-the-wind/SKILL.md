# Name The Wind

Call `wind-patterns`. Name the active pattern from this list when evidence supports it:

1. Complexity as credibility
2. Perfection over progress
3. Tool obsession
4. Analysis without action
5. Ignoring political reality
6. Solo heroics
7. Hiding uncertainty
8. Methodology over outcome
9. The permanent draft
10. Feature creep

For each named pattern give the evidence path or quote, the cost, and whether the forge line should stop. Prefer stopping the line over shipping a platform nobody asked for.

Follow project instructions and THE_WAY.md. Use native host tools, respect permissions, and distinguish observed evidence from assumptions.
