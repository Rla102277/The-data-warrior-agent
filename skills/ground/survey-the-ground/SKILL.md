# Survey The Ground

Inspect real source, configuration, schemas, tests, data lineage and deployment manifests. Identify systems of record, ingestion boundaries, transformation layers, orchestration, secrets boundaries and operational ownership. Report observed facts with paths and separate unknowns. For data platforms inspect key definitions, late-arrival handling, retries, data quality, observability, lineage and environments. Name only the tools the terrain actually contains. Record the repo host from the Scroll or from observed remotes/CI files (GitHub, Azure DevOps, etc.) without assuming one. Do not assume a vendor. Do not invent resources or architecture diagrams unsupported by evidence.

Follow project instructions and THE_WAY.md. Use native host tools, respect permissions, and distinguish observed evidence from assumptions.
