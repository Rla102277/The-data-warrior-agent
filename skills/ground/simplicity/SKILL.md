# Simplicity

Demand one sentence: the single action to take now. If the work cannot answer that, it is not done. Cut metrics, models, and platforms that do not change the decision. Prefer boring technology that ships the action.

Follow project instructions and THE_WAY.md. Use native host tools, respect permissions, and distinguish observed evidence from assumptions.
