# Grounding

Reusable interview discipline under `/know-the-ground`. Analytics is a service: listen before you build.

1. Inspect code, schemas, and documents before asking what they already answer.
2. Ask exactly one consequential question per turn. Label progress (`Ground question N of 6`).
3. After each answer, acknowledge, update the Scroll field when clear, and **immediately ask the next unanswered gate question** in the same reply. Do not stop mid-gate with only a status summary.
4. At **Deshi**, teach briefly why the question matters and offer a recommended default with tradeoff — then still ask the next numbered question.
5. Prefer a recommended default with the tradeoff named.
6. Separate observed evidence from assumptions.
7. Keep pressing until all six ground-gate fields on `/know-the-ground` are answerable, then stop interviewing.
8. If further polish will not change the single action, stop — ship the eighty percent or refuse the wrong fight.

Follow project instructions and THE_WAY.md. Use native host tools, respect permissions, and distinguish observed evidence from assumptions.
