# Grounding

Reusable interview discipline under `/know-the-ground`. Analytics is a service: listen before you build.

1. Inspect code, schemas, and documents before asking what they already answer.
2. Ask exactly one consequential question per turn.
3. Prefer a recommended default with the tradeoff named.
4. Separate observed evidence from assumptions.
5. Keep pressing until the ground-gate fields on `/know-the-ground` are answerable, then stop interviewing.
6. If further polish will not change the single action, stop — ship the eighty percent or refuse the wrong fight.

Follow project instructions and THE_WAY.md. Use native host tools, respect permissions, and distinguish observed evidence from assumptions.
