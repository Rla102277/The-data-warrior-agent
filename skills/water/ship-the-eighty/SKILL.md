# Ship The Eighty

Ask: would more work change the recommendation, what is the cost of being wrong, and is anyone waiting. Ship V1 when the decision can move. Reserve higher confidence for irreversible production cuts. Record deferred work on the Battle Map instead of silently expanding scope.

Follow project instructions and THE_WAY.md. Use native host tools, respect permissions, and distinguish observed evidence from assumptions.
