# The Pivot

Name the sunk cost without letting it decide. Pivot when a stakeholder cannot use the output, a proof keeps failing for structural reasons, or a simpler path answers the same action. Execute: freeze new features, rewrite remaining steps, preserve proven artifacts, and set a one-week bias to decide early. Do not pivot to chase novelty.

Follow project instructions and THE_WAY.md. Use native host tools, respect permissions, and distinguish observed evidence from assumptions.
