# See The Void

Call `void-sight`. Surface who gains, who loses, who must approve the feed or metric, and whether the system can be fixed from this seat.

If the source owner will never allow the feed, or the organization cannot act on the answer, write that on the Scroll as a blocker and stop the forge line. Do not invent org facts; mark unknowns.

Follow project instructions and THE_WAY.md. Use native host tools, respect permissions, and distinguish observed evidence from assumptions.
