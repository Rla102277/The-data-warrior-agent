# Chart The Path

Inspect code and decisions first. Define smallest shippable slice, dependencies, owners, contracts, migration strategy, failure recovery, tests and observable acceptance criteria. For data migrations include dual-run or reconciliation where warranted.

For a **rich campaign plan** (phases, Mermaid flowchart + mind map, evidence table, pass gates), the user should invoke `/to-plan` after the ground gate — not this discipline. Prefer a concise conversational plan here; persist only when work spans sessions, optionally via Battle Map. Never use “north star” wording.

Follow project instructions and the installed THE_WAY.md. Use native host tools, respect permissions, and distinguish observed evidence from assumptions.
