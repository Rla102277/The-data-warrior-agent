# GitHub setup

Clone, then run `python3 scripts/install.py /path/to/project the-scroll --host cursor` (or `claude` / `codex`). `THE_WAY.md` and role configuration are installed. Run `python3 scripts/sync.py --check` and `python3 scripts/verify.py` to validate this source repository. Existing project instructions are preserved. Do not commit credentials or private Scrolls to this public source repository.
