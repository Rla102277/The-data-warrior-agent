# GitHub and installation

Public source: https://github.com/Rla102277/The-data-warrior-agent

Clone or download, open in Cursor, and invoke commands directly. Use `python3 scripts/install.py /path/to/project` to install selected skills, or copy folders manually. Merge existing project instructions; don't overwrite them. Keep secrets and private project Scrolls out of this public repo. GitHub Actions checks file structure only.
