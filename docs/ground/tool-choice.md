# tool-choice

## What it does
Choose a tool only after the ground is known. Do not assume a platform or vendor. Compare fitness to the single action, including the status quo.

## When to reach for it
Use this discipline when the task matches the description above. Prefer `/ask-the-warrior` if you are unsure.

## Common questions
- Does this replace reading the code? No. Inspect evidence first.
- Can the model invent an approval? No. Humans approve production.
- Where do decisions live? In `SCROLL.md` via The Scroll.

## It's working if
The next forge stage is clear, evidence paths are named, and you can resume from files alone.
