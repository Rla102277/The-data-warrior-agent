# know-the-ground

## What it does
Grill the real decision before any forge build — all **six** gate questions, one per turn. After each answer, acknowledge and immediately ask the next (`Ground question N of 6`). At Deshi, teach between questions. Aligns to the manuscript's Ground book.

## When to reach for it
After setup, or when decision, owner, outcome, terrain, falsifiers, or single action are not yet on the Scroll. Prefer `/ask-the-warrior` if unsure.

## Common questions
- Does this replace reading the code? No. Inspect evidence first.
- Can we skip to the Forge? No. Technical completion without a named decision is not success.
- Why did it stop after one question? It should not. Re-invoke `/know-the-ground` or answer the current question — the next of six should follow in the same style.
- Where do decisions live? In `SCROLL.md` via The Scroll.
- Do we start from a platform? No. Record tools already on the terrain. Bring a new one only when the single action needs it.
- Files? Setup Menu G (and know-the-ground if missing) asks if you have files to upload or attach.

## It's working if
All six fields are on the Scroll, one sentence names the action, and `/to-spec` is the honest next step — or the honest next step is to refuse the fight. Turns never end mid-gate without the next numbered question.
