# know-the-ground

## What it does
Grill the real decision before any forge build. Aligns to the manuscript's Ground book: know the terrain, separate stated from real problem, demand one action in one sentence.

## When to reach for it
Starting a project or task when decision, owner, outcome, terrain, falsifiers, or single action are not yet on the Scroll. Prefer `/ask-the-warrior` if unsure.

## Common questions
- Does this replace reading the code? No. Inspect evidence first.
- Can we skip to the Forge? No. Technical completion without a named decision is not success.
- Where do decisions live? In `SCROLL.md` via The Scroll.

## It's working if
The Scroll holds the ground gate, one sentence names the action, and `/to-spec` is the honest next step — or the honest next step is to refuse the fight.
