# to-plan

## What it does
After the ground gate is on the Scroll, write a rich **campaign plan** (`PLAN.md`): aim of this fight, locked defaults, non-goals, Mermaid flowchart + mind map, evidence on the terrain, phases with pass gates, build order, and first concrete execution. No “north star” wording.

## When to reach for it
Ground is known; the fight is larger than one tiny step and needs a shared plan before `/to-spec`. Prefer `/ask-the-warrior` if unsure.

## Common questions
- Does this replace knowing the ground? No. Refuse without the ground gate.
- Does this replace `/to-spec`? No. Plan first (when needed), then spec, then steps, then forge.
- Mind maps? Yes — Mermaid `mindmap` in the same `PLAN.md`.
- Can we invent systems for a prettier diagram? No. Only what the terrain named.

## It's working if
`PLAN.md` is readable without the chat, phases have pass gates, both Mermaid diagrams render, and the next honest command is `/to-spec` or revise the plan — not a silent build.
