# test-the-steel

## What it does
Use when validating a code or data pipeline change, investigating failed tests, or proving correctness under replay, deletes and schema drift.

## When to reach for it
Use this discipline when the task matches the description above. Prefer `/ask-the-warrior` if you are unsure.

## Common questions

- Can the model invent an approval? No. Humans approve production.
- Where do decisions live? In `SCROLL.md` via The Scroll.
