# Architecture

Bucketed skills under `skills/<bucket>/<name>/SKILL.md` are the only canonical skill sources. User-invoked commands orchestrate. Model-invoked disciplines hold reusable practice. The Forge platform package (`forge` CLI, `forge-line/jobs/`) is the software line after the ground gate. Original Foundation-2.0 remains a separate folder on disk. Skills and Forge in this repository are MIT.
