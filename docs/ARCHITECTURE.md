# Architecture

Bucketed skills under `skills/<bucket>/<name>/SKILL.md` are the only canonical skill sources. User-invoked commands orchestrate. Model-invoked disciplines hold reusable practice.

The Forge is a file-based software factory process (spec, steps, proof, reviews, human approve). Job folders default to `forge-line/jobs/`. This repository does not ship a data platform package or Foundation codebase.
