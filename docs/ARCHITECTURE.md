# Architecture

Bucketed skills under `skills/<bucket>/<name>/SKILL.md` are the only canonical skill sources. User-invoked commands orchestrate. Model-invoked disciplines hold reusable practice.

The Forge software factory (`forge` CLI, `forge/line`, `forge-line/jobs/`) runs the ground-gated build line. Foundation estate knowledge (ops inventories, workplace runbooks) is out of scope for this repository.
