# the-battle-map

## What it does
Use when work spans multiple stages, contributors or sessions and needs an evidence-backed progress map and restart point.

## When to reach for it
Use this discipline when the task matches the description above. Prefer `/ask-the-warrior` if you are unsure.

## Common questions
- Does this replace reading the code? No. Inspect evidence first.
- Can the model invent an approval? No. Humans approve production.
- Where do decisions live? In `SCROLL.md` via The Scroll.

## It's working if
The map states objective, terrain, dependencies, actions, risks, decisions, and proof, and a later session can restart from those lines without trusting chat memory.
